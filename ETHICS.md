# ETHICS.md  

## Purpose  
This project — **Intelligent Password Profiling Tool** — is an **educational and defensive security tool**. Its goal is to demonstrate how personal information (names, hobbies, birth years, etc.) can make usernames and passwords predictable. By simulating these risks in a **controlled, local-only environment**, the tool helps users and security professionals understand weak patterns and learn how to improve password practices.  

---

## Ethical Use Statement  
- ✅ **For educational use only.**  
- ✅ **Local-only execution.** The tool must never be used against online systems, login pages, or accounts.  
- ✅ **Consent required.** Input data must be synthetic (fake), anonymized, or provided with the **explicit consent** of the individual involved.  
- ✅ **No credential attacks.** This tool generates and analyzes guesses but **does not attempt authentication** against any system.  
- ✅ **Awareness-focused.** The sole purpose is to raise awareness, strengthen password policies, and promote secure practices.  

---

## Prohibited Uses  
- ❌ Using this tool to try to gain unauthorized access to any account, system, or service.  
- ❌ Sharing generated guesses based on someone’s real personal information without their consent.  
- ❌ Deploying or modifying the tool for offensive security use without proper authorization and scope (e.g., a penetration test with a signed agreement).  

---

## Responsible Disclosure  
If during testing you discover real-world password vulnerabilities (e.g., weak default credentials in an organization you work with), you must follow **responsible disclosure practices** — report the issue through the appropriate channel, and never exploit it.

## Final Note  
Cybersecurity research is valuable when it is **responsible**. This project exists to help people understand risks, not to exploit them. Always act with integrity.
